# Arabam.com - Araba Satış Sitesi

Türkiye'nin en güvenilir araba satış platformu. Modern, responsive ve kullanıcı dostu bir arayüze sahip web uygulaması.

## 🚗 Özellikler

### Müşteri Özellikleri
- **Araba Listesi**: 8 örnek araba ile başlayan geniş araba veritabanı
- **İleri Filtreleme**: Marka, yıl, fiyat ve yakıt türüne göre filtre
- **Arama Fonksiyonu**: Hızlı arama ve filtreleme
- **Detaylı İnceleme**: Her araba için detaylı bilgiler ve resimleri
- **Satıcı İletişimi**: Doğrudan satıcıyla iletişim kurma seçenekleri
- **Responsive Tasarım**: Mobil, tablet ve masaüstü cihazlarla uyumlu

### Admin Panel Özellikleri
- **İlan Ekle**: Yeni araba ilanları ekleme
- **İlan Yönetimi**: Var olan ilanları düzenleme ve silme
- **Hızlı Erişim**: Yönetici paneline "Yönetici Paneli" linkinden erişim

### Diğer Özellikler
- Hakkında bölümü
- İstatistikler (İlan sayısı, müşteri sayısı, güvenlik oranı)
- İletişim formu
- Responsive mobil menü
- Modern ve şık arayüz

## 🛠️ Teknolojiler

- **HTML5**: Yapı ve semantik
- **CSS3**: Tasarım ve responsive layout
- **Vanilla JavaScript**: Tüm interaktif özellikler (Framework yok)

## 🚀 Nasıl Kullanılır

### 1. Projeyi Çalıştırmak

Tarayıcıda `index.html` dosyasını açın veya bir local server üzerinde çalıştırın.

### 2. Müşteri Olarak Kullanmak

1. **Anasayfada** araba listesini görüntüleyin
2. **Filtreler** bölümünde aranacak kriterleri seçin
3. **Arama kutusunda** marka veya model adını yazın
4. **Detaylar** butonuna tıklayarak arabanın tüm bilgilerini görün
5. **İletişim** butonuyla satıcıya ulaşın

### 3. Yönetici Olarak Kullanmak

1. Sayfanın üst sağında **"Yönetici Paneli"** linkine tıklayın
2. **"İlan Ekle"** sekmesinde yeni araba bilgilerini girin
3. **"İlanları Yönet"** sekmesinde var olan ilanları düzenleyin veya silin
